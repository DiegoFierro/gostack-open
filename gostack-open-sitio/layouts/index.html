Principios del curso

  • Un dominio, muchos adaptadores. La lógica de negocio no sabe si le habla un navegador, una API o una app móvil.
  • Lo explícito sobre lo mágico. Errores como valores, dependencias a la vista, herramientas simples.
  • Hipermedia primero. HTML desde el servidor y HTMX antes que un framework de JavaScript.
  • Medir, probar, observar. Benchmarks, pruebas, logs, métricas y trazas forman parte del camino, no un añadido.
